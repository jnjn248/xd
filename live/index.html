Chapter 05 · project teardown

一项嵌入式设计大赛作品，
怎样从赛题变成可交付的系统？

把一个比赛项目拆成五个连续环节。新生不需要一开始学会全部，可以先从其中一个环节加入，再逐步理解整套工程流程。

Embedded design workflow

从需求到答辩

每一步都有明确交付物

01 / DEFINE

拆赛题

把题目从一段文字变成可执行的任务清单，先明确"系统必须完成什么"。

  • 输入、输出与限制条件
  • 评分指标与验收方法
  • 功能流程图和时间表
交付：需求清单 + 方案草图
02 / DESIGN

定方案

比较不同实现路径，确定主控、传感器、执行器、通信方式和成本边界。

  • 模块划分与接口定义
  • 器件选型与风险评估
  • 软硬件分工与备选方案
交付：系统框图 + BOM
03 / BUILD

做硬件

将方案落成原理图、PCB 和样机，先让每个模块独立工作，再组合成系统。

  • 电源、接口与信号链路
  • 嘉立创 PCB 打样与焊接
  • 万用表、示波器和基础测试
交付：样机 + 硬件测试记录
04 / DEVELOP

写软件与算法

让系统完成采集、通信、控制和显示，必要时加入滤波、识别或智能算法。

  • C / C++、驱动与状态机
  • 传感器数据处理
  • 控制算法、视觉或边缘 AI
交付：可运行程序 + 测试用例
05 / DELIVER

联调答辩

在真实条件下验证指标，记录故障和改进过程，最后把结果讲清楚、演示出来。

  • 压力测试与故障复现
  • 性能数据与版本对比
  • 报告、视频与现场答辩
交付：完整作品 + 技术文档
新生怎么加入先选一个小模块，例如传感器采集、PCB 焊接、测试记录或答辩文档。
团队怎么协作硬件、软件、算法和项目管理按接口协同，每个人都有可验收的任务。
最后留下什么代码、原理图、测试数据和复盘文档，组成一份真正可展示的作品集。

02 · 现在就要做的事

大二下学期最关键

选择

确定体制内外倾向

走体制内还是体制外，最好在大二形成初步答案，大三用一年时间去验证和补齐能力。

  • 微控路线：课程 + 项目
  • 工控路线：抓住 PLC 课程
  • 考研路线：先定专业与梯度
四级

必须尽快拿下

四级不是加分项，而是很多校招和研发岗的基础门槛。没过四级，很多机会会在简历阶段被直接筛掉。

  • 每天固定词汇量
  • 真题反复训练
  • 不要拖到大四
作品

把经历变成证据

证书、代码、测试数据、复盘记录都要保留下来。最终能说服企业的，是你能讲清楚的完整项目结果。

  • 项目 README
  • 演示视频或照片
  • 量化成果
复盘

每学期一次决策

根据成绩、项目、竞赛和家庭情况调整路线。不要只听别人的选择，要形成自己的冲稳保方案。

  • 更新简历
  • 更新目标院校或岗位
  • 找老师和企业前辈确认
求职着装要求不能穿拖鞋、短裤、短裙、染发、五颜六色的衣服和比较凉爽的衣服。男生注意刮胡子、头发不要遮眉毛；女生可化淡妆、头发扎起来。建议购买白衬衣或白色 POLO 衫，搭配黑色直筒裤或与白色相搭的深色裤装。裤子长度不要盖住整个脚后跟。
简历与核心竞争力简历是展现给企业的"颜值"。GPA、四级和项目经历是基础盘；竞赛成绩和党员身份是加分项。千万不要挂科！
抓住大二关键期每个专业大二都会有人获得"大满贯"。走体制内还是体制外，最好在大二形成初步答案，大三用一年时间去验证和补齐能力。
Electrical Engineering Path

04 · 电气方向四年学习路径

从大一开始，按年度递进建立电气工程师的核心能力

大一

打牢基础

电气工程师的根基是电路和数学。大一要把电路原理和高等数学学扎实，同时了解电气工程的基本概念和就业方向。

  • 电路原理（基尔霍夫定律、欧姆定律、简单电路计算）
  • 高等数学（微积分、级数）
  • 了解电气工程师的工作内容和行业分布
  • 加入电气信息创新协会或相关社团
大二

建立专业框架

大二是分水岭。模电数电、电机学和自控原理是电气工程师的核心专业课，必须同时通过四级。

  • 模拟电子技术、数字电子技术
  • 电机学（变压器、异步电机、同步电机）
  • 自动控制原理、现代控制理论
  • 拿下英语四级，开始关注电气类竞赛
大三

聚焦方向 + 实习

大三要明确自己是走电网/供电局方向还是电力电子/新能源方向，同时争取进入实验室或企业实习。

  • 电力系统分析、继电保护、高电压技术
  • 发电厂电气部分、供配电设计
  • 参加电子设计竞赛、数学建模
  • 暑期实习或进实验室跟项目
大四

求职 / 考研冲刺

大四上学期是校招黄金期，电网一批考试通常在年底。根据大三的积累，选择电网考试、考研或直接就业。

  • 电网公司校园招聘或国家电网考试
  • 考研：电气工程（0808）或能源动力（0858）
  • 完善简历，突出项目经历和实习
  • 考取相关证书（电工证、注册电气工程师基础课）
Chapter 06 · postgraduate route

考研与升学：
目标应是稳上岸。

以下内容整理自《就业考研经验分享》。2024 级对应"28 考研"，预计时间为 2027 年 12 月 18—19 日。自动化常见方向是学硕 081100 控制科学与工程 和专硕 085406 控制工程。

Postgraduate Basics

01 · 基础规则

先认识考试，再选择路线

学硕

偏理论与研究

通常三年，注重学术研究和理论深度，可直博，但论文标准更高。学费一般 8000 元/年。

  • 政治 / 英语一（6000 词，5500 考纲 + 1000 超纲）
  • 数学一（高数 + 线代 + 概率论）/ 自控
  • 毕业压力大，论文标准高于专硕
专硕

偏实践与上岸

通常二到三年，重实践，备考压力相对小，学费 10000 元起；但竞争人数更多，部分强校仍考英一数一。

  • 政治 / 英语二（5500 词，全部为考纲词汇，难度比英一小）
  • 数学二（高数 + 线代，高数不需要学完）/ 专业课
  • 考博，适合目标为上岸的同学
时间

四科连续完成

第一天上午政治、下午英语；第二天上午数学、下午专业课。提前按真实时间做套卷训练。考研时间跟在四六级后面，四六级在 12 月第 2 个周末，考研在 12 月第 3 个周末。

  • 第一天：政治 8:30–11:30，英语 14:00–17:00
  • 第二天：数学 8:30–11:30，专业课 14:00–17:00
  • 重视专业课信息差
竞争

不要低估对手

控制工程不只和自动化竞争。自动化属于工科，但农学、理学、甚至文科都要来考控制工程——自控涉及数学比较多容易上手，对手远远不止自动化类。

  • 自动化类（机器人工程、轨道交通信号与控制）
  • 电气 / 电子信息 / 测控
  • 农学 / 理学 / 文科跨考
学硕 vs 专硕核心差异学硕学费约 8000 元/年，可直博，论文标准更高；专硕学费 10000 元起，考博，毕业难度较小。英语一需掌握 6000 词（含 1000 超纲），英语二需掌握 5500 词（全部考纲）。数学一含高数+线代+概率论，数学二仅高数+线代且高数不需学完。
录取现实2025 年广西科技大学共有 381 人考取硕士研究生（55 人"双一流"，43 人国外高校）。2026 年自动化学院毕业生 325 人，考研上岸仅 29 人，落实去向约 9%，但已是创新高。目标应为上岸，而非名校情结。
考研不能脱离自身背景高考分数、大学成绩、竞赛成绩以及地区情况都会影响结果。考研不是完全公平的考试，"赌博"成分大。抛掉自身条件不谈，上岸概率跌一半。
